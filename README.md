# TinderBot
A bot for automatic swiping and data scraping from the Tinder app. It was used to collect data later utilized in my Master's thesis: "Automating and Enhancing Dating Applications Using Machine Learning."

## Instructions
1. Create an account in the mobile version of Tinder via Facebook.
2. In the config.py file, fill in the email and password fields with your Facebook credentials.
3. Install all required libraries.
4. Run tinderbot.py.
